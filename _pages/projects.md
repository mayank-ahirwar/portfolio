## 1. Vision-Guided Underwater Object Detection and Robotic Manipulation

**Research Areas:** Computer Vision | Deep Learning | Vision-Guided Robotic Manipulation | Underwater Robotics

### Overview

This project focuses on developing a vision-guided underwater robotic system that integrates deep-learning-based object detection with robotic arm actuation. The system is designed to identify target objects in underwater camera footage, estimate their positions, and use this visual information to guide a robotic manipulator toward the objects for retrieval.

The project involves exploring and training deep learning models for underwater object detection, followed by the development of a vision-based control framework for robotic arm actuation.

### Objectives

- Detect and classify multiple objects in underwater camera footage.
- Display bounding boxes, object labels, and detection confidence scores.
- Estimate target-object positions from camera observations.
- Develop a vision-guided control strategy to actuate the robotic arm toward selected objects.
- Integrate object detection and robotic manipulation for underwater object retrieval.
