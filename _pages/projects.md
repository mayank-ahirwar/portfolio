## 1. Underwater Object Detection Using Computer Vision

**Area:** Computer Vision | Object Detection | Underwater Robotics | Python

### Overview

Development of a computer-vision-based object detection system
for identifying and locating multiple objects in underwater
environments. The project explores the use of pretrained deep
learning models for detecting objects from camera footage,
with a longer-term goal of integrating visual perception
into an underwater robotic manipulator.

### Objectives

- Detect multiple objects in underwater camera footage.
- Display bounding boxes, object class names, and confidence scores.
- Explore real-time detection using an underwater camera.
- Investigate integration with an underwater robotic manipulator.

### Tools & Technologies

**Python · PyTorch · Torchvision · OpenCV · CUDA**

### Project Development

The initial phase focuses on running pretrained object detection
models locally, processing recorded video, and saving annotated
detection results. The next phase involves testing with an
underwater camera and exploring robotic integration.

*Project in progress.*
